## Phase 1 Baseline Setup - 2026-07-01

## Question

What are the 3 independent baselines that all subsequent improvements (SA-ALW metric, Router, WBF) must beat?

## Baselines

### 1. YOLOv8n/v11n (full-image, no router, no RCNN)

**Code**: `scripts/train_yolo.py`

```bash
# YOLOv8n
python scripts/train_yolo.py --model yolov8n.pt --epochs 50 --imgsz 640

# YOLOv11n
python scripts/train_yolo.py --model yolo11n.pt --epochs 50 --imgsz 640
```

**Metrics**: mAP@50, mAP@50:95, mAP@75, Precision, Recall, AP_small/medium/large, FPS.

**Purpose**: Speed baseline. If cascade can't beat YOLO's speed-accuracy trade-off on easy regions, the router adds no value.

### 2. Faster R-CNN full-image (ResNet50-FPN, MaxIoUAssigner + SmoothL1)

**Code**: `common/` — uses `ciou` metric + `everywhere` placement.

```python
from common.model import build_model
from common.dataset import build_training_datasets
from common.config import seed_all

seed_all(42)
model = build_model(metric_fn=None, placement="everywhere")
train_ds = build_training_datasets(use_patches=False, is_train=True)
val_ds = build_training_datasets(use_patches=False, is_train=False)
```

**Purpose**: Standard Faster R-CNN reference. Baseline for ALL metric improvements in Phase 2.

**Config summary**:
- Backbone: ResNet-50-FPN (ImageNet pretrained)
- Anchors: 5 levels (4-1024 px), aspect ratios (0.5, 1.0, 2.0)
- Training: 20 epochs, SGD (LR=0.005, cosine + warmup 2 epochs)
- Batch: 4 (effective 16 via grad accum)
- EMA: decay 0.9998
- Input: tiles 512×512, overlap 64, min_size=640, max_size=800
- Augmentation: HFlip, brightness/contrast/saturation, copy-paste tiny objects

### 3. Faster R-CNN on patches (ResNet50-FPN, same model, patch training)

**Code**: `common/` — same model but `use_patches=True`.

```python
train_ds = build_training_datasets(use_patches=True, is_train=True)
val_ds = build_training_datasets(use_patches=True, is_train=False)
```

**Patch data**: Generated by `scripts/generate_patches.py` (context_ratio=1.5, patch_size=512).

| Split | Images | Patches | Patches/img |
|:-----:|:------:|:-------:|:-----------:|
| train | 1,371 | 9,863 | 7.2 |
| valid | 131 | 854 | 6.5 |

**Purpose**: Isolates the contribution of "patch-based training" from "SA-ALW metric" in later phases. Without this baseline, we can't tell if improvements come from better metric or just from patch-based refinement.

## Metrics Recorded for Each Baseline

| Metric | Source | Notes |

| mAP@50 | torchmetrics / YOLO val | Standard COCO threshold |
| mAP@50:95 | torchmetrics / YOLO val | COCO primary metric |

## Evaluation Protocol

1. **Lock test set**: No access until Phase 6. All tuning on validation (131 images, 4,382 objects).
2. **Multi-seed**: Run each baseline with 3 seeds {42, 123, 2024} for mean±std.
3. **Checkpoint selection**: Best by mAP@50 on validation (early stopping patience=5).
4. **Logging**: Per-epoch CSV in `runs/{config}/`. Metrics JSON in each run directory.
