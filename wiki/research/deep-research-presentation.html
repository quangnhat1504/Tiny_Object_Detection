🚨 Universal Bottleneck: AP@75

AP@75 stuck at 0.02–0.045 across ALL experiments

Root Cause

  • Regression loss: L = 1 − exp(−β·D_H) (Gaussian similarity)
  • IoU-insensitive by design — good for assignment, bad for precision
  • For 6px box: 1-2px error → high similarity → loss "satisfied" too early
  • RoIAlign 7×7 on P2 stride-4: 6px object = 1.5 feature cells → no spatial info

Both the loss function AND the feature resolution must be fixed

3. Regression Parametrization

🔴 HIGHEST PRIORITY — THE lever for AP@75

Loss Comparison for Tiny Boxes

Smooth-L1NoN/AModeratePoor
Gaussian sim.YesYesNo (saturates)Excellent
GIoUYesWeakGoodModerate
DIoUYesStrongGoodGood
CIoUYesStrongBestv noisy

Recommended: Dual-Objective with DIoU

if epoch < warmup (3):
    L = 1 − S_H                              # Gaussian only

elif epoch < transition_end (8):
    γ_eff = γ × (epoch − warmup) / (trans − warmup)
    L = (1 − S_H) + γ_eff × DIoU_loss        # ramp up

else:
    L = (1 − S_H) + γ × DIoU_loss            # full dual
  • γ = 0.3–0.5 (NOT 1.0 — notebook 10 confirmed too aggressive)
  • DIoU > CIoU: center penalty robust, no aspect-ratio quantization noise
  • Gaussian term: stability + scale invariance (keep!)
  • DIoU term: precision at high overlap + gradient at zero overlap

Why DIoU over CIoU for <8px

  • Center penalty is the dominant need — 2px error on 6px box → IoU=0.24
  • CIoU aspect ratio term v: arctan(6/10) − arctan(7/10) = 0.007 — swamped by quantization
  • DIoU: non-zero gradient even for non-overlapping boxes

Expected: AP@75 +2-4% with proper scheduling

⚠️ Mosaic Pitfall for Tiny Objects

  • Standard mosaic: 4 images → resize to fit → objects shrink 2×
  • 4px objects → 2px → undetectable
  • Fix: Crop 512×512 from each image, assemble without resize

Copy-Paste is Better

  • Extract micro object crops → paste into other images
  • Maintains object size, increases density controllably
  • More targeted than mosaic for this dataset

Key Findings

  1. Replace IoU with Gaussian distance in matching — #1 most impactful (✅ already done)
  2. Guarantee min positives per GT — SimOTA/PAA can assign 0 (✅ RFLA guarantees k)
  3. Scale-adaptive k validated: SCALE_TOPK won AP_micro in ablation (✅ done)
  4. Feature resolution > assignment sophistication — P2 gave +29% AP_micro

Execution Roadmap

Phase 1 — Fix AP@75 bottleneck

  • (a) DIoU regression, scheduled ramp-up (γ=0.3, warmup=3)
  • (b) RoIAlign 14×14 + conv head (notebook 14)
  • (c) Combine winner of (a) + (b)
  • Target: AP@75 > 0.06, mAP ≥ 0.58

Phase 2 — Stack micro gains

  • (d) Scale-adaptive k (k_micro=6) on Phase 1 winner
  • (e) Multi-resolution training (640-1024)

Phase 3 — Advanced (if plateaued)

  • (f) 2-stage Cascade + Gaussian thresholds
  • (g) Copy-paste augmentation

5 Key Principles

  1. Fix the loss first — no arch change fixes AP@75 if loss doesn't reward precision
  2. One variable at a time — NB9's 5-variable confound was a lesson
  3. RoIAlign + loss are complementary — information × incentive, need both
  4. Label assignment is near-optimal — bottleneck is now in the head
  5. Multi-scale training = easy wins — should be default, not an experiment
