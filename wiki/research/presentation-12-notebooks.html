📊 Tổng Quan Thực Nghiệm

Mục Tiêu

Tìm kiếm metric và architecture tối ưu cho phát hiện tiny objects (< 32px)

Dataset: TinyPerson

  • 70,702 objects trên 1,570 images
  • 79.5% objects có sqrt(area) < 20px
  • 92.1% objects có sqrt(area) < 32px
  • Trung bình 45 objects/image

Phân Tích Nguyên Nhân

🔍 Tại Sao P2 Thất Bại?

Vấn Đề Architecture

  • P2 stride-4 quá fine cho large objects
  • Memory/compute overhead cao
  • FPN không balance tốt P2-P5

Vấn Đề Training

  • Anchors chưa retune cho P2
  • RPN proposals chưa optimize
  • NMS threshold chưa điều chỉnh

Vấn Đề Data

  • Large objects ít (8% only)
  • P2 over-focus on tiny, neglect large
  • Imbalanced scale distribution

Vấn Đề Implementation

  • P2 RoI Align chưa tối ưu
  • Feature fusion suboptimal
  • Cần more tuning

🔧 Cần Cải Thiện

  • P2 implementation cần rework:

    • Consider RoI Align variations

🚀 Hướng Nghiên Cứu Tiếp Theo

Priority 2: Improve Localization

Priority 3: Architecture Exploration
